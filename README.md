# 红利定投 · 股息复投计算器

一个单文件 HTML 应用，专为按权重定投高股息股票设计。所有数据存放在浏览器 localStorage，无需后端、无需安装。

## 如何使用

### 1. 打开应用

直接双击 `index.html` 即可在浏览器中打开（推荐 Chrome / Edge）。

### 2. 初始化配置

- 点击右上角 **⚙️ 设置**，填写：
  - **每月定投基础金额**（如 ¥20,000）
  - **起投月份**
  - **是否开启股息自动复投**
  - **最小买入单位**（默认 100 股，A 股 1 手）
  - **买入费率**（如万 1.5 填 0.015）

### 3. 配置标的

进入「**持仓管理**」标签：
- 点击 **📌 载入示例** 可一键导入你截图中的 4 只红利股示例
- 或者点击 **+ 新增标的**，填写代码、名称、当前价、目标权重%
- 权重合计需为 100%

### 4. 每月操作流程

#### 4.1 生成定投计划
进入「**定投计划**」标签：
- 选择定投月份
- 基础金额默认沿用设置中的值
- 调整"本次追加"（如有）
- 选择是否将待投股息计入
- 点击 **🔄 生成本月计划**

系统会显示每个标的：
- 基础分配（按权重）
- 上月顺延（不足 1 手累积下来的钱）
- 实际分配 = 基础 + 顺延
- 买入股数（必须是 100 整数倍）
- 实际支出
- 顺延下月（仍买不起 1 手的部分）

#### 4.2 录入实际成交
点击「**→ 去执行记录**」：
- 调整实际成交价（可能略偏离计划价）
- 调整实际买入股数（可能没有买满）
- 填写备注
- 点击 **✅ 全部确认到账**

确认后系统自动：
- 更新持仓股数 + 成本
- 把顺延金额累积到下月 owed
- 写入历史记录

#### 4.3 记录股息收入
进入「**股息管理**」标签：
- 选择股息所属月份（一般 A 股 6-7 月集中派息）
- 填每股股息或实收金额（系统会自动按持有股数算）
- 点击 **💾 保存股息记录**

如果开启股息自动复投，**未使用完的累计股息**会在下次定投时作为额外资金按权重分配。

### 5. 查看资产看板

「**资产看板**」标签汇总：
- 当前持仓市值
- 累计净投入
- 累计已收股息 + 待投股息
- 总资产 = 市值 + 累计股息
- 累计盈亏 + 综合收益率（含已收股息）

## 算法说明

### 核心：DCA + 凑整手顺延

每个月的资金分配算法：

```
可用资金 = 基础定投 + 追加 + 待投股息
对每个标的:
  分配 = 基础定投 × 权重 + 已有顺延
  若分配 ≥ 1手价格:
    买 = floor(分配 / 1手价格) × 1手
    剩余 = 分配 - 买出金额  → 归为 "surplus"
  否则:
    剩余 = 分配 → 归为 "defer"（顺延下月）

surplus 按权重重分配给 "已能买更多" 的标的（一次分配，不迭代）
defer 累积到该标的的下月分配
```

### 为什么 surplus 只分给"能买"的标的？

如果一个标的当前 alloc 都买不起 1 手，再给它 surplus 大概率也凑不到 1 手，不如让有钱的标的先多买。

### 顺延机制示例

假设中国移动单手价 ¥10,530：

| 月份 | 基础分配 | 累计顺延 | 总分配 | 操作 |
|---|---|---|---|---|
| 第 1 月 | ¥4,000 | ¥0 | ¥4,000 | 全部顺延（差 ¥6,530） |
| 第 2 月 | ¥4,000 | ¥4,000 | ¥8,000 | 全部顺延（差 ¥2,530） |
| 第 3 月 | ¥4,000 | ¥8,000 | ¥12,000 | 买 1 手 (¥10,530)，剩 ¥1,470 分给其他 |

## 数据备份

- **导出**：右上角 📤 → 保存 JSON 文件到本地
- **导入**：右上角 📥 → 选择 JSON 文件恢复
- **重置**：清空所有数据（不可恢复，请先导出备份）

## 注意事项

- 当前价格需要**手动更新**（A 股实时行情接口一般需要付费或券商权限）
- 实际买入时建议用券商 App 成交，再回到这里录入实际价格和股数
- 此工具为**计划/记录工具**，不直接下单交易
- 股息数据需要按实际情况录入（可参考券商 App 的交割单）
